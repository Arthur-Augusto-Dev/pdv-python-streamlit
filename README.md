# 🛒 PDV Pro - Sistema de Ponto de Venda com Python

Este é um projeto de *Ponto de Venda (PDV)* completo, desenvolvido para facilitar o gerenciamento de vendas, controle de estoque e emissão de comprovantes. A interface foi construída utilizando *Streamlit*, proporcionando uma experiência de uso fluida e moderna diretamente no navegador.

## 🚀 Funcionalidades
* *Caixa Registradora:* Adição de produtos, cálculo automático de total e finalização de vendas.
* *Banco de Dados:* Armazenamento robusto utilizando *SQLite* para persistência dos dados.
* *Relatórios:* Visualização de vendas e métricas em tempo real.
* *Comprovantes:* Geração de comprovantes de venda de forma organizada.

## 🛠️ Tecnologias Utilizadas
* *Linguagem:* Python
* *Interface:* Streamlit
* *Processamento de Dados:* Pandas
* *Banco de Dados:* SQLite
* *Controle de Versão:* Git & GitHub
